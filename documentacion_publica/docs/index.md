# Diputado de Distrito

## Comprender, comprobar y reutilizar

DDD construye y estudia distritos uninominales a partir de unidades censales oficiales. Es un **mapa de investigación sin valor oficial**. Esta documentación recoge solo contenido estable: método, fuentes, datos abiertos y cómo citarlos.
