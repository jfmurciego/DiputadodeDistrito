# Ensayo PV-EDGE-01 — objetivo global de compactación por adyacencia

- Hipótesis: el MILP exacto con restricciones de población, provincia, municipio, unidades y congelación puede hallar una partición conectada si el objetivo primario maximiza las aristas entre unidades asignadas al mismo distrito, en vez de minimizar movimientos. Una arista interna adicional domina lexicográficamente todos los posibles cambios de unidad; el segundo objetivo minimiza movimientos entre las soluciones con igual número de aristas internas.
