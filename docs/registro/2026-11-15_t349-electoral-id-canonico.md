## 2026-11-15 — T-349 — El paquete electoral registrado con id no canónico no se reutiliza (Activación, P12, puertas)

Causa (confirmada en los logs del piloto aut11, intento 2): la Activación 43701739818 planificó REUSE del paquete electoral `ddd-electoral-package-extremadura-2025-42720735134` porque `resolver_preparacion_legislatura._electoral_candidate` (y `preflight_preparacion_fuente`, `validar_puerta_ejecucion`, `validar_elegibilidad_incorporacion_electoral`, `resolver_ejecucion_completa`) aceptaban el nombre del artefacto con cualquier variante (`variantes()` = id nuevo o viejo). La puerta 03→04 (`validar_paquete_electoral`, comparación exacta del manifiesto) lo bloqueó después: «territorio o edición no coincide». Mismo defecto que T-336 (#806) en la rama de fuentes; en el catálogo vivo, 71 de 74 recibos electorales llevan el id viejo.

Cambio: igualdad EXACTA con el id canónico (sin alias ni reescritura). Un registro electoral o territorial con id viejo → `*_ID_NO_CANONICO` (NOT_ACCREDITED) → ACQUIRE: la Activación/03 prepara uno nuevo. `preflight` devuelve `registered=false` + `rejected_reason=ID_NO_CANONICO`. P12 (1.0.15): el paso «Recuperar paquete electoral registrado» rechaza y prepara de nuevo si el nombre o el `territory_id` del manifiesto no son canónicos; el resumen dice PREPARÓ/REUTILIZÓ con el id y falla si reutiliza uno no canónico. Puertas y elegibilidad: nombre exacto.

Pruebas: `tests/test_t349_electoral_id_canonico.py` (17: caso aut11, canónico, nac con id viejo, plan vivo de Extremadura, bloques `run:` reales del P12 bajo `bash -eo pipefail`; rojas en `main`); smoke T-339 con el preflight de aut11; actualizados 4 tests de `test_preparacion_legislatura_vigente` que daban por reutilizable el registro vivo con id viejo.

Riesgos y efectos: los 71 registros electorales con id viejo pasan a ACQUIRE (regenerar con 03/Activación; `reutilizar_si_ya_preparada=false` ya lo hacía). `catalogo_preparacion.py validate` sigue aceptando alias en el catálogo (solo valida estructura; no selecciona). No toca M04/M05. Requiere 00 «Generar desde fuente» o Activación tras fusionar.
