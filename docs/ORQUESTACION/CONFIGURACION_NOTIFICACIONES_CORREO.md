# Configuración de correo para la orquestación DDD

**Versión:** 1.0.0

El repositorio ya publica una mención a `@jfmurciego` en el issue #5 cuando termina cada workflow registrado.

Una única comprobación manual en GitHub asegura el correo:

1. Abrir el issue #5 y pulsar **Subscribe** si no figura como suscrito.
2. En GitHub, **Settings → Notifications**, activar el correo para **Participating, @mentions and custom**.
3. Confirmar que la dirección de correo de GitHub está verificada.

No se usan claves SMTP, servicios externos ni secretos del repositorio.
