# T-423 · Preview de la V4 (portada + Explorar = V3 completa con doble vuelta)

Capturas con Playwright (escritorio 1440×900 a deviceScaleFactor 2; móvil iPhone 13) de un sitio local montado con los
mismos pasos que P40 (`datos/` desde los blobs del registro, secciones del seccionado 2025, documentación con Zensical).

**Los datos de doble vuelta de estas capturas son de EJEMPLO FICTICIOS** (votos inventados por distrito para poder pintar
el mapa): no son resultados. En el sitio real la capa lee lo que deja P40 en `v4/mapa/datos/` (`herramientas/publicar_doble_vuelta.py`).

1. Portada · 2. Explorar, vista nacional, «Tres bloques» · 3. Explorar, Madrid a nivel de sección censal ·
4. Ficha de un distrito con primera y segunda vuelta · 5. Metodología y 6. Datos con la cabecera, el menú único y el pie de la V4.
