# Procedimiento controlado posterior

Esta secuencia describe condiciones futuras, no una autorización vigente.

1. Work aprueba y registra en el contrato de Congreso: unidad mínima, contigüidad, límites poblacionales expresados sin herencia, indivisibilidad municipal, islas, enclaves y discontinuidades. Resolver también el bloqueo contractual `CIRCUMSCRIPTION_COVERAGE_NOT_ACCREDITED_52_OF_52` con evidencia correspondiente.
2. Volver a ejecutar el preflight para la provincia 10 sobre las mismas fuentes y producto acreditados. Exigir M01–M04 PASS, M05 con condiciones declaradas y M06 contrato PASS; las funciones informativas no pueden habilitar producción.
3. Revisar las 11 discontinuidades municipales con la regla aprobada y comprobar que los hashes de fuentes y grafo siguen coincidiendo. Si cambia cualquier entrada, detener y recalcular la acreditación afectada.
4. Work emite autorización separada, expresa y acotada para un ensayo Cáceres K=3. Solo entonces se puede preparar una invocación productiva controlada M01–M06; este encargo no contiene esa autorización ni una configuración ejecutable.
5. Ejecutar una vez la orden autorizada, revisar trazabilidad CUSEC/población, cuota 3, provincia, componentes, límites aprobados y auditoría final M06. No publicar productos sin autorización adicional.

Hasta que se cumplan esos requisitos, `generation_authorized` permanece `false` y el comando de preflight sigue siendo de solo diagnóstico.
